# Якоря Хаоса — переделка (согласовано)

## Сеть
- Все Якоря владельца — одна сеть сразу, без смыкания кругов.
- Якоря ставятся только в Лучезарии. В других мирах — отказ, Якорь возвращается. Старые Якоря вне Лучезарии работают, но в сеть не входят.
- Набег: один отсчёт на сеть, цель — Якорь рядом с владельцем. Гарнизон всей сети прыгает к атакованному Якорю.
- Дуги между колоннами — только между близкими Якорями (украшение).
- Минимальное расстояние 96 остаётся.
- Бонус энергии: растёт с числом Якорей сети до ×5. Дальше каждый Якорь даёт другой бонус (выбрать при обсуждении улучшений).

## Опыт Якоря
- Опыт = осквернённые блоки + пассивный прирост + перелив.
- Уровень считается по опыту; пороги прежние (300/800/1600/3000).
- Захват края — только по реально осквернённой земле (300 блоков), не по уровню.
- После 5-го уровня излишек уходит в запас сети; запас делится поровну между растущими Якорями, коэффициент 50%. Нет растущих — копится, новый Якорь берёт сразу.
- Перелив может поднять Якорь до 5-го уровня скачком (колонна, радиус, попытки, места печатей) — это ускорение, не захват.
- Нить за уровни, полученные переливом, — половина обычной награды.

## Пассивный прирост
- Захваченный Якорь: +1 опыта в минуту за уровень, пока участок загружен.
