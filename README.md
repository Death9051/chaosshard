# Осколок Хаоса — мод-ядро (Forge 1.12.2)

Версия **0.1.0**, первая веха. Мод-ядро одноимённой сборки: Преддверие, Нить и связка с Astral Sorcery.

## Что уже есть

### Преддверие (своё измерение, ID 66)
- Остров из **хаосита** с верхним слоем **корки Преддверия**. Остров висит в пустоте, поверхность на Y = 130: алтари Astral Sorcery собирают полный свет с Y ≥ 120.
- **Вечная ночь**: небо всегда в полночь. Погоды нет, облака под островом.
- Мобы сами не появляются. Руды нет: Преддверие бедно материей.
- **Первый вход в мир** переносит игрока в Преддверие, Гримуар встречает репликой.
- **После смерти** без кровати тело собирается заново в центре Преддверия. Под ногами достраивается площадка, сундуки при этом не трогаются.

### Нить
- Хранится на игроке, переживает смерть и синхронизируется с клиентом.
- Уровни 1–5 по порогам 100 / 300 / 700 / 1500 / 3000 очков (меняется в конфиге).
- Каждый уровень выдаёт этап Game Stages `nit_1` … `nit_5`. Этап `nit_0` выдаётся при первом входе.
- Новый уровень Нити Гримуар сопровождает репликой.
- **Шкала на экране** появляется при приседании и на 5 секунд после изменения Нити.

### Звёзды (нужен Astral Sorcery)
- **Созвездие Хаоса**: восьмилучевая звезда. Видно каждую ночь, ритуалы и кристаллы с ним не ломают игру. Сам ритуал пока пустой.
- **Небо по мирам:**
  - **Преддверие** — все созвездия сразу, в полную силу, и максимум звёздного света: ночь всегда глубокая, любое место «лучшее». Порядок созвездий сдвигается каждую ночь, чтобы телескоп за несколько ночей показал все.
  - **Лучезария** (верхний мир) — обычное небо Astral плюс Хаос.
  - **Прочие миры с небом** (Кладовки и т. п.) — только Хаос, нарисованный поверх родного неба.
- На небо добавлено 4 места для созвездий: в Astral их 15, а созвездий вместе с Хаосом 17.

## Команды (уровень оператора)
`/chaosshard` или короче `/oh`:

| Команда | Что делает |
|---|---|
| `/oh nit get [игрок]` | показать уровень и очки Нити |
| `/oh nit set <игрок> <очки>` | задать очки |
| `/oh nit add <игрок> <очки>` | добавить очки (минус — убавить) |
| `/oh nit resync [игрок]` | заново выдать этапы Game Stages |
| `/oh tp antechamber [игрок]` | в Преддверие |
| `/oh tp world <id> [игрок]` | к точке появления измерения |
| `/oh sky` | какие правила неба действуют здесь и какие созвездия активны |

Квесты Better Questing могут начислять Нить наградой-командой: `/oh nit add VAR_NAME 50`.

## Связь с Astral Sorcery через CraftTweaker
Пример скрипта: `examples/scripts/chaosshard_stars.zs`, положить в `scripts/` сборки. Он делает две вещи:
- ограничивает уровень перков по уровню Нити: 5 → 10 → … → 30;
- позволяет открыть созвездие Хаоса в телескопе с `nit_1`.

## Конфиг
Файл `config/chaosshard.cfg`. В нём три раздела:
- **antechamber** — ID измерения, высота и радиус острова, телепорт при первом входе, возрождение;
- **thread** — пороги уровней, префикс этапов, команды выдачи и снятия этапов, шкала на экране;
- **stars** — список измерений Лучезарии и переключатели каждого правила неба.

## Сборка jar

### У себя
1. Поставить JDK 21 (например, Liberica или Temurin).
2. В папке проекта выполнить `gradlew.bat build` (Windows) или `./gradlew build`.
3. Первый запуск качает Minecraft, Forge и маппинги, это несколько минут.
4. Готовый файл: `build/libs/chaosshard-0.1.0.jar`.

### Через GitHub
1. Загрузить проект в репозиторий.
2. Workflow `.github/workflows/build.yml` соберёт jar сам.
3. Jar будет во вкладке Actions, в артефакте `chaosshard-jar`.

### Запуск в среде разработки
`gradlew runClient`. Astral Sorcery и Baubles подтянутся сами.

## Что нужно в сборке
- Forge 14.23.5.2860.
- **MixinBooter** 10.7 или новее: без него правила неба не работают.
- **Astral Sorcery** 1.10.27 и Baubles.
- **Game Stages** + Bookshelf: для этапов Нити.
- **CraftTweaker**: для скрипта перков.

Just Enough Dimensions для стартового измерения больше не нужен: мод сам переносит игрока в Преддверие.

## Как проверялось
- Код компилируется против заглушек API Minecraft, Forge, Astral Sorcery и MixinBooter. Настоящая компиляция в этом окружении невозможна: репозитории Forge и Mojang закрыты.
- Цели миксинов, имена полей и сигнатуры сверены с исходниками Astral Sorcery для 1.12.2. Сигнатуры Forge сверены с исходниками ветки 1.12.x.
- Отдельный ревьюер прошёлся по именам API (MCP stable_39), найденные ошибки исправлены.
- Логика уровней Нити и классификации миров покрыта мини-тестом.
- JSON-файлы проверены, ключи перевода сверены с кодом.

**В игре мод ещё не запускался.** Первая настоящая сборка — `gradlew build` у вас или в GitHub Actions.
